Phantom Eye

Hidden Camera Detection System
Status: Work in Progress

About

Phantom Eye is a smart hidden-camera detection system designed to identify potential surveillance devices using multiple detection techniques. The project focuses on improving personal privacy and security in unfamiliar environments.

Core Features

  • Infrared reflection detection
  • Network-based device scanning
  • Computer vision-assisted analysis
  • Potential ESP32 / RF integration
  • Real-time room scanning concepts

Technology Stack

  • JavaScript / Mobile integration concepts
  • Computer Vision
  • AI-assisted detection logic
  • IoT & sensor experimentation

Vision

The long-term vision for Phantom Eye is to create a portable and accessible privacy-security tool that can help users detect suspicious surveillance devices quickly and effectively.

Current State

Currently in research and prototyping stage. Detection methods, scanning techniques, and feasibility studies are actively being explored.
