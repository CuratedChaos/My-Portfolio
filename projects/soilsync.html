SoilSync

Status: Work in Progress

About

SoilSync is an IoT-based smart farming system designed to monitor soil conditions and automate irrigation intelligently. It aims to reduce water wastage and improve crop efficiency using real-time data.

Core Idea

  • Soil moisture monitoring
  • Automated irrigation control
  • Sensor-based decision making
  • Real-time data tracking

Tech Stack

  • ESP32 / Microcontroller
  • Soil moisture sensors
  • Relay modules for motor control
  • IoT integration (planned)

Current State

Prototype and logic design in progress. Future scope includes cloud integration and mobile monitoring.
